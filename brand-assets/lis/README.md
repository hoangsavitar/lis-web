Kích thước gốc 11812 × 5486px, có alpha. Bản web tại public/brand/lis/ rộng 512px và 1024px, giữ tỷ lệ và alpha, không thay hình dạng. Đỏ thương hiệu #630D1A.

Dùng node scripts/build-brand-assets.mjs để tạo lại các bản web từ logo gốc đã lưu. Đường dẫn UI được quản lý trong data/site.ts.
